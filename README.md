# lostwall

把音乐节的现场设成手机锁屏，上面用大字印一行「捡到请联系 138 8888 8888」。
手机丢了，捡到的人按一下电源键就知道打给谁——不用解锁，不用装东西。

纯前端，零后端，零构建。照片和号码不出你的浏览器。

## 为什么做这个

音乐节散场，人挤人，手机从兜里没了。捡到的人拿到一台锁屏手机：有密码进不去、
不知道是谁的、手机还静音。大概率交给保安，或者塞进包里。

手机壳纸条要提前想到，医疗急救卡入口太深，"查找" App 得有两个设备。
壁纸是唯一一个**不用解锁、一按电源键就看见**的位置。

## 三个入口

| 入口 | 要什么素材 | 适合谁 |
|---|---|---|
| **通用款** | 无 | 只想 10 秒出一张能用的 |
| **音乐节** | 选一个，可印真实节目单 | 想有点调性的乐迷 |
| **自己的照** | 一张现场照 | 想用自己拍的那张 |

## 重要：号码必须是另一台手机的号

壁纸上的号如果就是这台手机的号，捡到的人打过去，响的是他手里这台。

**填家人、备用机或同事的。**

## 部署到 GitHub Pages

不用构建，推上去就能用。

```bash
git clone https://github.com/nex627/lostwall.git
cd lostwall
# 改完
git add . && git commit -m "update" && git push
```

仓库 **Settings → Pages → Source: Deploy from a branch → main / (root)**。
推上去等一分钟，访问 `https://nex627.github.io/lostwall/`。

> 项目页地址带子路径 `/lostwall/`，所以 HTML 里的资源全部用相对路径（`./src/app.js`）。
> 改成绝对路径 `/src/app.js` 会在 Pages 上全部 404。

## 本地跑

直接双击 `index.html` 就行。没有模块、没有依赖、没有编译。

改完刷新页面即可，不用重启任何东西。

## 加一个音乐节

**没有节目单的音乐节不会出现在列表里** —— 一张查不到时间表的海报只是占位。
所以加一场要同时改两个文件。

`src/festivals.js`，一行一个基本事实：

```js
{ id: 'midi', name: '迷笛', en: 'MIDI', cities: ['北京', '苏州', '深圳'], months: [5, 10] },
```

- `months` 是**惯例月份**，不是本年官宣日期。
- 列表按「距离下一次惯例月份」排序；已结束但有节目单的保留，标「纪念款」。
- 只列 `src/lineups.js` 里有对应节目单的音乐节。

## 节目单：只印能查到出处的

海报上的「几点几分哪个乐队」是**事实**，所以这里有一条硬规矩：

> 每一份节目单都必须带 `source` 和 `year`，海报上印的年份就是数据本身的年份。

拿 2025 年的阵容贴上 2026 的标签，是这个项目唯一会被一眼看穿并直接失去信任的错法。
数据里 `year: 2025`，海报上就一定印 `2025.06.01 – 06.02`。

目前内置一份：**2025 长沙草莓音乐节 · 草莓舞台**（两天 24 组，来自官方公布的演出时间表）。

**为什么只有一份。** 国内音乐节的分钟级时间表几乎只以**图片海报**形式发布，
2024 台州迷笛、2025 阿那亚虾米都只能查到「按日阵容 + 舞台开场收场时间」，
查不到逐组的开演时刻。文字版能核实的样本很少，所以不硬凑。

**其余音乐节怎么办：** 界面里给了一个「粘一份自己的节目单」的输入框，
照着官方图片敲进去就行：

```
6.01 SUN
20:40-21:30 痛仰
20:00-20:40 陈绮贞
19:20-20:00 陈粒
```

时间写在行首或行尾都认；没有时间的行会当成日期分段。
解析在 `src/lineups.js` 的 `parseLineup`，不联网，也不猜。

**加一份内置节目单：** 往 `G.LINEUPS` 里加一个对象，`days[].acts` 按时间正序：

```js
{
  id: 'xxx2026', festId: 'strawberry', year: 2026, city: '上海',
  name: '上海草莓音乐节', stage: '草莓舞台', dateLabel: '2026.05.01 – 05.03',
  source: '2026 上海草莓音乐节官方演出时间表',
  days: [{ label: '5.01 FRI', acts: [{ t: '13:30', n: '乐队名' }] }]
}
```

## 已知限制

- **iOS Safari 不能直接下载到相册**，只能长按图片 → 存储到照片。
- 微信内置浏览器保存图片受限，会提示用系统浏览器打开。
- 播放器/壁纸设置时会做轻微「透视」缩放，所以信息带上下各留了 8% 安全边距。
- 号码字号是屏宽的 8%（约等于锁屏时间大字的大小）。**故意不追求画面和谐**——能在三米外读出来，比好看重要。

## 隐私

- 照片用 `FileReader` / `URL.createObjectURL` 本地读取，画在 Canvas 上，`toBlob` 导出。
- 号码只存在 `localStorage`，右上角没有账号，没有请求，没有埋点。
- 打开开发者工具的 Network 面板，除了 HTML/CSS/JS 本身，没有任何请求。
